# 2.20Y-I18N-04 — Shell closure, locale selector and Clerk localization

Mandato para cerrar formalmente I18N-03 y agregar únicamente selección y
persistencia de locale junto con la localización sincronizada de Clerk.

## Alcance autorizado

- Auditar, stagear explícitamente, commitear y publicar sólo I18N-03;
  preservar `.vscode/tasks.json` fuera de Git.
- Agregar en el footer de usuario un selector visible para `es-419`, `pt-BR` y
  `en`, con el locale server-side como estado canónico.
- Persistir una preferencia allowlisted en la cookie `pimienta_locale` mediante
  Server Action y refrescar la ruta actual sin modificar la URL.
- Alimentar `ClerkProvider` desde el mismo locale con recursos oficiales y un
  mapping tipado.
- Validar tests focalizados, typecheck, lint, build y diff final.

## Límites

No se autorizan routing por locale, DB o Clerk metadata, migraciones de
formularios/Zod/formatos/features, cambios de tenancy/RBAC/Store, provider,
scheduler, deploy ni cierre Git de Y04.

## Resultado

I18N-03 quedó auditado y publicado como
`68cbd896a07c9646a297727165134518483b134e`. I18N-04 implementa localmente el
selector, una cookie de 365 días y `router.refresh()`. Clerk usa
`@clerk/localizations@4.6.4` con `es-419 → es-MX`, `pt-BR → pt-BR` y
`en → en-US`. Y04 permanece sin stage, commit, push ni deploy.
