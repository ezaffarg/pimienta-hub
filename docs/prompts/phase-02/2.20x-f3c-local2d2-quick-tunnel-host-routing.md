# 2.20X-F3-C-LOCAL-2D2 — Quick Tunnel Host header routing

## Objetivo

Corregir exclusivamente el routing del Quick Tunnel temporal haciendo que
`cloudflared` entre por Traefik con el Host esperado por Pimienta Hub.

## Alcance autorizado

- Verificar versión y sintaxis instalada de `cloudflared`.
- Resolver el origin local que alcanza Traefik sin pasar directamente al
  contenedor Next.js.
- Iniciar exactamente un Quick Tunnel con `Host: pimienta-hub.test` hacia el
  origin Traefik ya probado.
- Validar públicamente health, root y callback con payloads sintéticos seguros.
- Construir, sin registrar, la URL OAuth temporal para el siguiente gate.

## Límites

- Cero provider calls, OAuth, refresh, maintenance o scheduler.
- Cero cambios en Coolify, Traefik, hosts, firewall, DNS o producto.
- Cero escrituras en Mercado Libre Developers.
- El tunnel permanece temporal y sólo puede quedar activo si health y callback
  pasan, para que el siguiente bloque reutilice el mismo hostname.
- No hacer commit ni push.

## Resultado requerido

El checkpoint debe confirmar la capacidad `httpHostHeader`, el origin usado,
el hostname público, la eliminación del 404, callback/idempotencia sintética,
fixtures residuales y readiness para el provider test 2D3.
