# Fase 2.20X-F3-B2-R1 — Controlled product rename

Fecha: 2026-08-31. Estado: **IMPLEMENTACIÓN LOCAL PASS**.

## Antecedente y decisiones

La auditoría F3-B2 recomendó renombrar el producto antes de F3-C. R1 fija
**Pimienta Hub** y `pimienta-hub`, mientras difiere dominio y nuevo asset
OpenGraph. `supabase.project_id`, URLs externas, GitHub, Clerk, Mercado Libre,
Sentry, Coolify y la carpeta local permanecen intactos.

## Alcance

R1 cambia únicamente branding activo, package/workspace metadata, metadata
Next.js, documentación canónica y referencias activas de skills. Preserva
prompts anteriores, `README_OLD.md`, el análisis inicial de Cursor, migrations,
SQL, contratos DB, identifiers `Hub*`, env names, credenciales y comportamiento
productivo.

## Validación y checkpoint

La metadata de Bun quedó frozen-consistent sin cambios de dependencias. Pasaron
los tests focalizados (4/4), la suite (365/365), typecheck, lint y build local.
El primer typecheck encontró un `validator.ts` generado y truncado bajo
`.next/dev/types`; se eliminó sólo ese artefacto ignorado y el reintento pasó.

El postcheck amplio de `e-ngenieria`/`e-Hub` deja 88 referencias permitidas:
81 en prompts históricos, cuatro en
`README_OLD.md`/`docs/Cursor-AnalisisInicio.md` y tres técnicas preservadas
(`e-ngenieria-architecture`, `supabase.project_id` y un comentario de
migración). El enlace GitHub al upstream Kiranism y el asset heredado
`shadcn-dashboard.png` se preservan; el nuevo asset OpenGraph queda pendiente.

R1 modificó 42 referencias activas en 22 archivos, sin cambiar comportamiento,
URLs externas, contratos DB, migrations, entorno, Supabase local ni recursos
remotos. El audit final de diff no detectó churn ni cambios fuera de alcance.
