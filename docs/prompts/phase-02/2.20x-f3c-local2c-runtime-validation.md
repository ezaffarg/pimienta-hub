# 2.20X-F3-C-LOCAL-2C — Runtime validation

Prompt operativo archivado desde el mandato aprobado para validar el pipeline
2.20X en el laboratorio Coolify local contra Supabase remoto.

## Alcance autorizado

- Validar configuración runtime sin imprimir secretos.
- Probar autenticación de la ruta interna de mantenimiento.
- Ejecutar una única invocación autorizada de mantenimiento.
- Validar observabilidad, intake, idempotencia, processing, retry, freshness/CAS
  y stale reclaim con fixtures sintéticos aislados cuando resulte seguro.
- Validar el callback público Mercado Libre sólo con notificaciones sintéticas.
- Inspeccionar la capacidad de Scheduled Tasks de Coolify y crear una tarea
  local cada cinco minutos únicamente si todos los gates previos pasan y el
  secreto puede permanecer fuera de la configuración y los logs visibles.
- Observar como máximo dos ejecuciones programadas y limpiar todos los fixtures.

## Límites

- Sin Hostinger, DNS productivo, infraestructura productiva ni cambios a la
  aplicación Mercado Libre Developers.
- Cero llamadas o escrituras al provider.
- No imprimir secretos, customer payloads ni material sensible.
- No modificar recursos reales ni ejecutar deletes amplios.
- Preferir cero cambios de producto. Un defecto real se reporta como
  `RUNTIME_CODE_GAP` y no se corrige automáticamente.
- No cambiar migrations; ante un defecto de migration, detenerse.
- Los únicos cambios rutinarios permitidos son este prompt y su índice.
- No ejecutar suite completa, build, typecheck o lint si no cambia producto.
- No hacer commit ni push.
