# 2.20X-F3-C-LOCAL-2B2 — Supabase Key Incident Recovery

## Objetivo

Recuperar el incidente causado por la exposición accidental de la credencial
legacy `service_role`, verificar que Pimienta Hub usa la nueva Supabase Secret
API Key de forma server-only y corregir exclusivamente la portabilidad de la
matriz SQL de mantenimiento sobre un remoto poblado.

## Alcance autorizado

- Verificación segura de configuración local y runtime Coolify sin imprimir
  secretos.
- Inspección read-only del estado de la credencial legacy; no se autoriza
  deshabilitarla automáticamente.
- Cambio mínimo únicamente en
  `supabase/tests/2.20x_f_event_maintenance_matrix.sql`.
- Validación local y una ejecución remota de esa matriz sólo si su transacción,
  fixtures y rollback prueban aislamiento completo.
- Confirmación read-only de las cinco migrations X ya aplicadas.

No se autorizan cambios productivos, migrations, provider writes, scheduler,
tunnel, Hostinger, commit ni push. `.vscode/tasks.json` debe preservarse.

## Gate de cierre

El bloque sólo puede recomendar runtime validation cuando la credencial nueva
funcione en Coolify, no exista material secreto en el repositorio, la matriz
corregida pase local y remotamente con conteos intactos, y el estado de la
credencial legacy quede clasificado sin exponer valores.
