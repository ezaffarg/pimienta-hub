# 2.20X-F3-C-LOCAL-1 — Local Coolify + Remote Supabase Readiness

## Objetivo

Auditar en modo read-only un laboratorio productivo local antes de contratar o
usar un VPS: Windows → Docker Desktop/WSL2 → Coolify local → Pimienta Hub →
Supabase remoto.

## Baseline

- Repositorio: `ezaffarg/pimienta-hub`, branch `develop`.
- Base esperada: `c6dc39a45bf98a0641809d3cdca2b500cfe6c11a`.
- Docker Desktop se reporta operativo.
- Coolify se reporta disponible localmente, pero su instalación real debe
  descubrirse sin asumir topología ni puertos.
- Supabase local puede permanecer activo, pero no es el destino de esta prueba.

## Alcance

- Descubrir containers, redes, volúmenes, proxy, salud y URL de Coolify local.
- Verificar read-only si existen Project, Environment, Application y GitHub
  Source relacionados con Pimienta Hub.
- Confirmar el contrato Dockerfile/standalone y el inventario de variables.
- Verificar conectividad e historial de migrations del Supabase remoto sin
  mostrar secretos ni ejecutar writes.
- Definir estrategias locales para URL, Clerk, Mercado Libre, health y
  scheduler y preparar el plan LOCAL-2.

## Exclusiones

No crear ni editar recursos Coolify, desplegar, aplicar migrations, modificar
Supabase remoto, tocar los containers Supabase locales, cambiar providers,
iniciar tunnels, crear scheduler o modificar firewall.

## Estado

LOCAL-1 es sólo auditoría/preflight. LOCAL-2 requiere un gate explícito y no
comienza hasta entregar este checkpoint.
