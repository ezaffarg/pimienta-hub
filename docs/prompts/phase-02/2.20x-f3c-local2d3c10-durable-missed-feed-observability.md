# 2.20X-F3-C-LOCAL-2D3C10 — Durable missed-feed observability

## Objetivo

Agregar mediante una única migration forward observabilidad durable y segura
para que un maintenance run conserve el stage exacto del fallo missed-feed y
los conteos exactos de provider calls attempted/succeeded.

## Alcance autorizado

- Agregar sólo campos mínimos a `integration_event_maintenance_runs`.
- Extender las RPC de checkpoint/finalize preservando tenant, RLS,
  `SECURITY DEFINER`, `search_path` y privilegios.
- Actualizar repository, types y servicios en los límites existentes.
- Contar attempts inmediatamente antes de cada request y successes después de
  una respuesta aceptada por el client boundary.
- Mantener `missed_feed_failed` como error de alto nivel y persistir únicamente
  un stage seguro, sin payloads, tokens ni datos de cliente.
- Validar casos credential, identity, missed-feed HTTP, respuesta inválida,
  cero eventos, eventos y cooldown.
- Validar primero localmente y sólo entonces aplicar la migration forward al
  proyecto remoto canónico y verificar su contrato read-only.

## Límites estrictos

- Provider calls, maintenance real, OAuth, reconnect, refresh y scheduler: 0.
- No cambiar semántica de recovery ni cooldown de 15 minutos.
- No modificar el run histórico ni completar retroactivamente datos UNKNOWN.
- No UI, payloads libres, tracing general, refactors laterales, commit o push.
- Preservar `.vscode/tasks.json` y los cambios legítimos de 2D3C9.
- Minimal Diff / No Churn; una sola migration aditiva.

## Resultado

- Migration forward aditiva aplicada local y remotamente.
- Stage allowlisted y counters attempted/succeeded persisten mediante checkpoint,
  finalize y summary sin payloads ni secretos.
- Runs históricos conservan NULL/UNKNOWN; runs nuevos parten de 0.
- Caller antiguo y nuevo validados mediante `supabase-js -> PostgREST .rpc()`
  tanto localmente como, con IDs inexistentes y cero writes, en remoto.
- Reset local PASS; matriz nueva 6/6 y regresiones X-F/F2b 16/16 PASS.
- Tests focalizados 36/36, typecheck y lint PASS.
- Credencial real versión 4, vigente y lease CLEAR; run histórico intacto.
- Provider calls, maintenance real, OAuth, reconnect y scheduler: 0.
