# 2.20Y-I18N-02 — i18n foundation implementation

Mandato para implementar la base mínima de internacionalización de Pimienta
Hub después del audit 2.20Y-I18N-01.

## Alcance autorizado

- Instalar la versión estable de `next-intl` compatible con Next.js 16 y
  React 19 usando Bun.
- Definir `es-419`, `pt-BR` y `en`; `es-419` es default y `en` fallback.
- Resolver una preferencia explícita, la cookie allowlisted
  `pimienta_locale`, `Accept-Language` y finalmente el default.
- Crear catálogos pequeños `common`, `navigation` y `shell`, con fallback
  anidado no mutante y contratos TypeScript prácticos.
- Configurar requests App Router sin locale routing y hacer dinámico el
  atributo `lang` del root layout.
- Probar resolución, fallback, estructura, seguridad de imports y pruebas
  server/client mínimas sin traducir superficies productivas completas.
- Documentar la arquitectura canónica y validar tests focalizados, typecheck,
  lint, build y `git diff --check`.

## Límites

No se autorizan prefijos de URL, selector, escritura de cookie, localización de
Clerk, migración masiva de copy, formatting Y05, cambios de DB, scheduler,
provider calls, deploy ni cierre Git. `.vscode/tasks.json` debe permanecer
untracked, intacto y fuera de staging.

## Resultado

Foundation implementada localmente con `next-intl@4.14.0`, resolución
allowlisted, fallback inglés no mutante, catálogos iniciales, request config y
`<html lang>` dinámico sin routing por locale ni provider global. Tests i18n
28/28, typecheck, lint y build pasaron; el build conservó únicamente el warning
informativo conocido de Google Sans Flex. No hubo DB, provider, deploy ni
cierre Git.
