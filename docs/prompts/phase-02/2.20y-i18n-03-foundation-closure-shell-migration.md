# 2.20Y-I18N-03 — Foundation closure + global shell migration

Mandato para cerrar formalmente I18N-02 y migrar únicamente el shell global de
Pimienta Hub a la foundation `next-intl` ya implementada.

## Alcance autorizado

- Auditar, stagear explícitamente, commitear y pushear sólo los 28 archivos de
  I18N-02; preservar `.vscode/tasks.json` fuera de Git.
- Inventariar el shell real y traducir sólo navegación, sidebar, header,
  breadcrumbs, command/search, estados globales y metadata que efectivamente
  pertenezcan al shell.
- Mantener IDs, rutas, permisos, RBAC, feature flags y valores dinámicos sin
  cambios; traducir en el boundary de render.
- Ampliar sólo `common`, `navigation` y `shell`, conservar paridad y usar APIs
  server-first o providers cliente acotados.
- Validar tests focalizados, typecheck, lint, build y diff final.

## Límites

No se autorizan selector ni escritura de cookie, localización Clerk, routing
por locale, migración de forms/Zod/formatting/features, cambios de DB,
scheduler, Mercado Libre, deploy ni cierre Git de Y03. El commit y push
autorizados corresponden exclusivamente a I18N-02.

## Resultado

I18N-02 quedó auditado, commiteado y publicado como
`9113ebf16a9a153e8cf08a55b5d63b999741aa14`. I18N-03 migró localmente sólo el
shell global mediante traducción en el render boundary y un provider dashboard
acotado a `navigation`/`shell`; IDs, URLs, RBAC y valores dinámicos permanecen
sin cambios.

La matriz focalizada pasó 39/39 junto con typecheck, lint y build; el único
warning del build fue el fallback conocido de Google Sans Flex. I18N-03 queda
sin stage, commit, push ni deploy. Selector/cookie, Clerk, formatos,
validaciones y migración de features continúan diferidos.
