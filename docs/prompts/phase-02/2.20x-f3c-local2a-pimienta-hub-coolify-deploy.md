# 2.20X-F3-C-LOCAL-2A — Deploy Pimienta Hub to Local Coolify

## Objetivo

Desplegar Pimienta Hub una sola vez en la instalación existente de Coolify
local y validar build, runtime, Traefik, health y conectividad read-only con
Supabase remoto.

## Infraestructura confirmada

Windows → WSL2 Ubuntu 24.04 → Docker separado → Coolify 4.3.14 → Traefik. La
ruta local `coolify-test.test` ya demuestra routing y despliegue Next.js; esa
aplicación debe preservarse.

## Alcance autorizado

- Reutilizar o crear Project `Pimienta Hub` y Environment `Local Lab`.
- Crear una Application desde `ezaffarg/pimienta-hub`, branch `develop`.
- Usar exclusivamente el `Dockerfile` canónico y puerto interno 3000.
- Configurar variables existentes sin imprimir valores, usar
  `http://pimienta-hub.test` como URL del laboratorio y generar un secreto M2M
  nuevo sólo dentro de la configuración segura local.
- Disparar un único deployment y auditar container, logs, health y conectividad
  read-only con Supabase remoto.

## Exclusiones

No aplicar migrations, modificar Supabase remoto, Clerk, Mercado Libre o
Sentry, iniciar tunnel, crear scheduler, usar VPS/Hostinger, tocar Supabase
local ni exponer directamente el puerto 3000.

## Estado

LOCAL-2A es el gate de deployment local previo a LOCAL-2B. Si aparece un fallo
de acceso o código, debe detenerse y documentarse antes de reintentar.
