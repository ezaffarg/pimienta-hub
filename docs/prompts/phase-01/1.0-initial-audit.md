## Resultado

El proyecto era el starter Kiranism `next-shadcn-dashboard-starter`: tenía un dashboard feature-based, Clerk, TanStack, Zod, tablas y gráficos, pero utilizaba mocks en memoria. No tenía persistencia, tenant de datos, API protegida de forma completa ni integración funcional con Mercado Libre.

## Decisiones derivadas

- Conservar el layout, Clerk, TanStack Query/Form/Table, Zod y el patrón `features/<feature>/api`.
- Introducir PostgreSQL/Supabase como persistencia, sin usar Supabase Auth.
- Separar `features/` de `integrations/mercadolibre/`.
- Resolver `orgId`, `storeId` y permisos en servidor.
- No copiar endpoints internos de MercadoCuentas; usar la API oficial de Mercado Libre.
